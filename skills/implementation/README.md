# Implementation skills

This folder contains implementation-focused guidance and templates for backend, frontend, mobile-friendly workflows, and API changes.

- `backend.md`: Backend implementation guidance and deliverables.
- `frontend.md`: Frontend implementation guidance and deliverables.
- `templates/`: Reusable templates for API endpoints and UI components.

Use these as the canonical place for implementation tasks and prompt patterns.

Every implementation should identify its user workflow, data contract, failure/retry behavior, authorization boundary, tests, migration needs, and documentation updates.
